# 설교 노트

주일 설교를 들으면서 바로 받아 적는 개인용 앱. 아이폰 홈 화면에 추가해서 사용.

## 기능

- 말씀 찾기: 책 이름 앞글자 자동완성(`마` → 마태복음·마가복음), 책→장→절 탭으로 선택(여러 절은 처음·끝 절 탭), 또는 직접 입력(`요한복음 3장 16절`, `요 3:16-21`, `히 12 2`, `시편 23편`) / 🎤 음성
- 고른 말씀은 노트에 포스트잇처럼 붙고, 여러 개 붙일 수 있음
- 노트 구성: 날짜 → 설교 제목 → 본문 말씀(포스트잇) → 받아 적기
- 자동 저장 (이 기기의 localStorage)
- 목록에서 날짜·제목·말씀·내용 검색, 월별 칩, 달력으로 날짜 찾기
- 목록의 노트를 왼쪽으로 밀면 삭제/취소 버튼
- 설정: 성경 번역 코드, 백업(내보내기/가져오기)
- 본문 조회가 안 될 때는 다른 성경앱에서 복사해 "직접 붙여넣기"

## 구조

- React (create-react-app) — 운동 앱 FORGE와 같은 방식
- `src/bible.js` : 책 이름/약어 파싱 + Bolls Life API로 본문 조회
- `src/App.jsx` : 목록·검색 / 노트 작성 / 설정
- 배포: GitHub에 push → Vercel 자동 배포 (무료)

## 배포 방법 (Vercel)

1. vercel.com → Add New → Project → 이 저장소 Import
2. Framework는 Create React App으로 자동 인식 → Deploy
3. 아이폰 Safari에서 배포 주소 열기 → 공유 → "홈 화면에 추가"
4. 이후 코드가 바뀌면(push) 자동으로 새 버전이 배포됨

## 알려진 한계 / 확인할 것

- 본문 번역은 기본값 `KRV`(개역한글). 교회에서 쓰는 개역개정은 저작권 문제가 있어 무료 API로 보장되지 않음 → 설정에서 코드 변경 가능, 안 되면 직접 붙여넣기
- 아이폰 홈 화면 앱 모드에서는 앱 내 🎤 버튼이 동작하지 않을 수 있음 → 키보드 🎤 받아쓰기를 쓰면 됨
- 노트는 기기 localStorage에만 저장 → 가끔 백업
